## 실행 방법
1. **권장:** `SISTECH_EARTH_demo_실행.bat` 더블클릭 → 브라우저가 자동으로 열립니다.
2. **온라인 주소(영구, GitHub Pages):** https://signspark.github.io/sistech-earth/
   - 저장소: https://github.com/signspark/sistech-earth (index.html 교체 후 커밋하면 1~2분 내 반영)
   - 휴대폰에서도 열립니다.
3. HTML 파일을 그냥 더블클릭(file://)하면 지구 지형 계산용 워커가 차단되어 **지구가 검게 보일 수 있습니다.** 그 경우 1번을 쓰세요.

## 조작
- 왼쪽 메뉴: 카테고리 → 레이어. 연두색 점 = 켜짐. "준비 중" = 데이터 연동 예정, "SITE 전용" = 3D 모델 위에서만 제공.
- 지도 클릭 → 오른쪽 지점 카드 (날씨·대기 레이어가 켜져 있을 때 값 표시).
- 하단 시간 바: -24h ~ +120h. 움직이면 지점 카드 값이 그 시각 예보로 바뀜. ▶ 는 5일 자동 재생.
- 상단 EARTH / SITE: 모드 전환. SITE는 가장 가까운 프로젝트로 이동.
- 측정 › 거리/면적: 클릭으로 점 찍기, 더블클릭으로 끝. Esc 종료.
- 검색(⌕): 도시·주소(OpenStreetMap) 또는 프로젝트 이름.
- 주소창 해시(#at=...)에 위치·레이어가 저장되어 링크 공유 가능.
- **EARTH 버튼**(상단 탭 또는 왼쪽 레일)을 누르면 SITE에서 열어둔 창(지점 카드·측정·하위 메뉴·설정·검색·궤도 선)이 모두 닫힙니다.

## v2 (2026-10-04 저녁) · EARTHUS 전 기능 탑재
EARTHUS 소스의 현상 레지스트리(66+19 현상, 109 레이어)를 기준으로 우주탐험을 제외한 전 메뉴를 넣었습니다. 분류: ✅48 구현 · 🔁7 대체 구현 · 🔑3 키 필요 · ⏳20 준비 중 → 상세는 `EARTHUS_전기능_카탈로그.md`.
- **격자 필드 엔진**: 현재 화면 범위를 16×11(전지구 20×10)로 샘플링해 열지도·범례·화살표(바람·해류)·H/L 기압 중심을 그림. 시간 바(-24h~+120h) 연동. 한 번에 하나만 켜짐(EARTHUS live= 방식). Open-Meteo 무료 한도(분당) 초과 시 1분 후 재시도 안내.
  - 날씨: 기온·강수·바람·기압·습도·시정·토양수분·내일 최고/최저/바람·열돔 / 바다: 파고·너울·해수면온도·해류 / 대기: PM2.5·PM10·AQI·오존·먼지·자외선
- **레이더**: RainViewer 전지구 합성 10분 프레임, 시간 바 연동(과거 2h~+30min)
- **벡터**: JMA 태풍(실황·예보원·폭풍역), NASA EONET 자연재해/산불, USGS 지진, 판 경계(PB2002), 해구 20곳, 해양 환류, 오늘의 극값, OSM 관광지·해변·낚시터·활공장·산 정상(화면 범위), GBIF 조류·철새·바다거북·바닷새
- **지점 카드 섹션**: 서핑·낚시·패러글라이딩·산 정상 판정, 기후 시계열(ERA5 365일), 평년차(5년 대비), 인구(WorldPop 10km)
- **공통**: 물어보기(규칙 기반 질문 → 레이어 켜기+이동), 리포트(HTML 인쇄/JSON/CSV), 설정 구름 모드(없음/관측/모델/정적)·눈얼음, 지형 음영·바다 깊이·산림 손실 타일
- 준비 중(키/프록시 필요): 기상청 특보·AWS·천리안, METAR, 쓰나미, 낙뢰, 선박, 항공편, 부이, Argo, 해수면 상승, 뉴스, 서울 혼잡, EARTHUS 자체 관광 카탈로그

## 실제로 연결된 데이터
- **SISTECH 3D-View 타일셋 (인천-1·부산-1·분당-1·고양-1)**: 현장 근처(60 km)로 가면 자동 로드. 모델 위 클릭·높이 측정 가능

- CelesTrak 궤도요소 + satellite.js SGP4: 한국 위성·지구관측 위성·ISS 29기, 스타링크, 현장 통과 예보
- Launch Library 2 로켓 발사 일정
- Esri World Imagery (영상), Esri Reference (지명)
- USGS 지진 피드 (M2.5+, 7일)
- NASA GIBS: VIIRS Black Marble(밤의 불빛), MODIS Terra(어제 구름)
- Open-Meteo: 지점 기상(GFS·ECMWF), 대기질(CAMS)
